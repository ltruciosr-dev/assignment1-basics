# Claude Code Instructions

## Testing
- You can run specific tests using: `uv run pytest -k (test_name)`
- Always run tests to verify functionality after code changes

## Code Review Approach
- When reviewing code or finding issues, **DO NOT** apply fixes directly
- Instead, explain which parts of the code are not well implemented
- Provide hints and guidance to help the developer fix the issues themselves
- Focus on identifying problems and suggesting approaches rather than providing complete solutions

## Development Guidelines
- Prefer editing existing files over creating new ones
- Only create files when absolutely necessary for the task
- Follow existing code patterns and conventions in the codebase
